# Included third-party assets

Unpolished Bees packages the original, unmodified Kenney asset archives below.
Their `License.txt` files remain beside the assets.

- [Kenney UI Pack](https://kenney.nl/assets/ui-pack) — CC0. Used for the
  application font, controls, icons, and restrained click sound.
- [Kenney Cursor Pack](https://kenney.nl/assets/cursor-pack) — CC0. Used for
  the normal, action, text, pan, and tile-picker cursors.

The `roag_assets/` staging directory is an intentional source handoff of
ROAG’s existing art sources. Keep each source pack’s supplied license and
attribution material with it when publishing or redistributing it.
