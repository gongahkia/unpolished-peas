# Third-party notices

PX-240C is private proprietary software. Its package manifests and lockfiles identify exact library
versions. Runtime redistribution will include only dependencies required by the exported player.

The initial development toolchain uses Rust crates and npm packages under their respective upstream
licences. Before a release-candidate build, this file will enumerate the resolved production
dependencies, copyright notices, licence texts, and whether each dependency is redistributed. No
third-party game code, palette, font, artwork, or audio is included.
