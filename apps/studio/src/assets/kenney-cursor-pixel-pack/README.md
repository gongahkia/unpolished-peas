# Kenney Cursor Pixel Pack

This directory contains the small, source-preserved subset of the **Cursor Pixel Pack** used by
the MOD-01 Studio and its in-console player HUD:

- `tile_0028.png` — monitor pointer
- `tile_0134.png` — actionable controls
- `tile_0120.png` — source and text entry
- `tile_0012.png` — unavailable or waiting controls
- `tile_0048.png` — interactive cartridge and authoring canvases

Source: <https://kenney.nl/assets/cursor-pixel-pack> (version 1.0, released 2024).
The upstream `License.txt` is retained verbatim. The art is released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/); acknowledgement is voluntary.
The files are bundled locally, so the Studio never fetches art at runtime.
